# Project: People’s Ability to Choose

## Overview  
This project replicates parts of Carlin et al. (2017) to analyze decision-making among 1,603 respondents choosing credit cards. Using **SQL** and **SAS**, 
I cleaned the data, calculated descriptive statistics, and analyzed how factors like age, gender, and income influenced choices.

## Analysis  
I performed data cleaning, cross-tabulations, and visualizations to explore the dataset. Key findings include: 48.8% chose the dominant card, 
males slightly outperformed females, and higher-income respondents made better choices. 
The implemental video without superfluous taglines led to the highest success rate (65%).

This project demonstrates my ability to handle data, perform statistical analysis, and derive insights using SQL and SAS. 
It highlights my skills in data cleaning, visualization, and decision-making analysis.
